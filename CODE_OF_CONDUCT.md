# Code of Conduct

## Our commitment

This project is committed to a respectful, inclusive, and harassment-free
environment for everyone who participates in issues, pull requests, and other
project discussions.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on ideas, evidence, and the project.
- Welcome different perspectives and experience levels.
- Respect privacy and do not share personal or sensitive information.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, deliberate
disruption, or publication of another person's private information without
permission are not acceptable.

## Enforcement

For a concern about specific GitHub content, use its **Report content** control
and choose **Report to repository admins** when that option is available. This
creates a private report for the maintainers. If that option is unavailable, or
the concern is about the project generally, use GitHub's
[abuse-reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
and identify `edsele/customer-churn`. Reports will be handled with appropriate
discretion. Project maintainers may remove content or restrict participation
when behavior violates this code of conduct.

This policy is informed by the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
